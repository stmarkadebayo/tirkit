# Experiment E1: can the LLM judge be trusted?

**Claim tested:** LLM judges are biased by position and length, and calibrating the rubric against
human labels improves agreement (SPEC §9).

E1 has two halves.

## 1. Position bias (no human labels needed)

`research/experiments/e1_judge_bias.py` asks the same model for a one-sentence and a 3-5 sentence answer to
each of the 50 questions in `research/evals/acme_qa.jsonl`, then has the judge compare each pair in both
orders, under the built-in `correctness` rubric (v0) and a calibrated rubric (v1).

```bash
python research/experiments/e1_judge_bias.py --base-url http://localhost:1234/v1 --model qwen/qwen3.5-9b
```

Output: `research/experiments/results/e1_flip_rate.json` (flip rate, first-position win share, long-answer
win share, every pair's verdicts).

## 2. Agreement with humans (needs the maintainer's labels)

Kappa needs real human labels; nobody can fill these in for you.

1. Send real outputs to Tirkit (the demo app or another app).
2. **Annotation → Score definitions:** create `correct` (numeric 1–5) with this guidance:
   5 fully correct and complete · 4 correct with a minor gap · 3 partly correct · 2 mostly wrong ·
   1 wrong or refused.
3. **Annotation → Queues:** create a queue collecting `correct`, fill it with 100–200 traces, and
   label them yourself (number keys, Enter to submit). Budget: about 1 hour for 100.
4. **Judge reliability:** run a report on that queue with the built-in `correctness` rubric (v0).
   Note kappa, weighted kappa and the length correlations.
5. Calibrate: read the disagreements, edit the rubric (explicit criteria, anchored examples, "ignore
   order and length"), run again. Each edit is a new rubric version with its own row. Stop when
   kappa stops improving.
6. Copy the before/after numbers, with n and the judge model, into the README Results table.

CLI equivalent: export the queue's labels (`Export labels` in the UI), then

```bash
tirkit judge-report labels.jsonl --label correct --rubric correctness --model <judge-model>
tirkit judge-report labels.jsonl --label correct --rubric my_rubric_v1.txt --model <judge-model>
```
