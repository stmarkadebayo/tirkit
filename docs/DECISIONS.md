# Tirkit: decision log

The main decisions are already made in SPEC.md §7. Record here every decision taken during the build
that fills a gap in SPEC.md or departs from it.

| # | Date | Decision | Options considered | Why | SPEC section |
| --- | --- | --- | --- | --- | --- |
| 1 | 2026-11-16 | Scope raised from an eval library with a CLI to a standalone product covering observability and evaluation at the level of LangSmith, Langfuse, Phoenix, Braintrust and Weave | Keep the library-only scope; full product | Maintainer's direction: Tirkit must stand as a product of its own. Old non-goal "no full web UI" removed | §1, §2, §3 |
| 2 | 2026-11-16 | Self-hosted open source, single organisation per deployment; no multi-tenant SaaS or billing | Hosted multi-tenant SaaS | Product-grade without billing and tenancy work; no paid cloud allowed under AGENTS.md compute rules | §2, §7 |
| 3 | 2026-11-16 | Postgres for the server, SQLite locally; no ClickHouse until a benchmark shows Postgres misses NFR-6 | ClickHouse from the start (Langfuse's route) | One database to operate; decide on measured data | §7, NFR-6 |
| 4 | 2026-11-16 | Postgres-backed job queue (`SKIP LOCKED`) for the worker | Redis + RQ/Celery | No extra service to run | §7 |
| 5 | 2026-11-16 | React + TypeScript + Vite UI served as static files by FastAPI | Server-rendered HTMX/Jinja | Trace trees, compare views and the playground need a client-side app | §7 |
| 6 | 2026-11-16 | No LLM gateway inside Tirkit | Build a proxy like Helicone | Any OpenAI-compatible gateway works with Tirkit; Tirkit does not need to be one | §2 |
| 7 | 2026-11-16 | Added NFR-5/6 (throughput, query latency), experiment E3 and matching README Results rows (all unmeasured) | — | A product needs scale targets; E3 tests whether online judge scores track real user feedback | §3.5, §9 |
| 8 | 2026-11-16 | Apache-2.0 for the whole repository; contributions under a CLA (.github/CLA.md) collected by the CLA Assistant Lite bot, signatures on the `cla-signatures` branch | MIT; AGPL server; Elastic License 2.0; DCO instead of a CLA | Apache-2.0 matches OpenTelemetry and most of the category and adds a patent grant. CLA.md is a first draft, not reviewed by a lawyer: get it reviewed before accepting outside contributions or forming a company | §7 |
| 9 | 2026-11-16 | Real outside users start right after the observability UI (new M6), not at the end | Keep users in the final milestone | A user's feedback should decide what the evaluation UI, prompts and online evals look like | PLAN |
| 10 | 2026-11-16 | Tirkit covers every model kind: text, vision, image generation, embeddings, small/local models, ASR/STT, TTS and speech-to-speech; media stored by content hash outside the database; usage and price generalised to tokens, seconds, characters and images | Text-only first, multimodal later | Owner's direction. Adding media and non-token usage to the span model now avoids a schema migration later | §3.5 |
| 11 | 2026-11-16 | Trace summaries are recomputed per write batch with one window-function statement (`ROW_NUMBER`/`SUM … OVER`), not per trace | Per-trace queries; triggers; incremental counters | Per-trace refresh cost 3 round trips per trace and capped ingestion at ~400 spans/s; the batch statement reached 5,400 spans/s in the store and stays idempotent under re-delivery | §4, NFR-5 |
| 12 | 2026-11-16 | API-key secrets are argon2-hashed like passwords, with verified keys cached in memory for 60 s | SHA-256 for high-entropy keys | Follows NFR-7 literally; the cache keeps the hash off the ingestion hot path | NFR-7 |
| 13 | 2026-11-16 | OTLP mapping follows the GenAI conventions in open-telemetry/semantic-conventions-genai (they moved out of the main semconv repo) plus OpenInference attributes | Only one convention | Most LLM instrumentation in the wild emits one of the two | FR-6 |
| 14 | 2026-11-16 | Web UI pinned to React 18.3, Vite 5.4, TypeScript 5.7, Recharts 2.15 and built with npm | Latest majors (React 19, Vite 8, TypeScript 7, Recharts 3); pnpm | Established versions with well-known APIs; npm ships with Node so contributors need nothing extra. Upgrading the majors is a follow-up | M5 |
| 15 | 2026-11-16 | UI API types are hand-written in `web/src/api.ts`, not generated from OpenAPI | Generate a client from the server's OpenAPI schema | Most endpoints return free-form JSON without response models, so a generated client would be mostly `unknown`. Generate once the endpoints declare Pydantic response models | M5 |
| 16 | 2026-11-16 | UI checked in a real browser during development; no Playwright suite yet | Playwright end-to-end tests in CI | Browser binaries are heavy for CI; server behaviour is covered by API tests. Adding Playwright for the main flows is open work | M5 |
| 17 | 2026-11-16 | Public regression/QA set: 50 questions hand-written over the demo app's documents (`research/evals/acme_qa.jsonl`) | A slice of SQuAD | SPEC §5 allows either. A set over the demo docs lets the same questions drive the demo app, E1 pairs and the E2 seeded regressions with no download or licence terms. Written during the build, not by the owner | §5 |
| 18 | 2026-11-16 | Free local models for development and E1/E2: Qwen 3.5 9B and Nomic embeddings through LM Studio's OpenAI-compatible server | Paid APIs | AGENTS.md compute rules: no paid APIs beyond the .env budget. Caveat for E1: the judge and the answer model are the same small model, which the write-up must state | §9 |
| 19 | 2026-11-16 | Search is indexed: SQLite FTS5 kept in sync by triggers, Postgres generated `tsvector` (`simple` config) with a GIN index, over span name, input and output (first 200,000 characters each). Every query word must match as a word prefix; a trace matches when any of its spans does; symbol-only queries fall back to substring matching | Substring `LIKE` (the first version); Postgres language-specific configs | Word-prefix matching is what users expect from a search box and stays fast as data grows; `simple` avoids guessing the language of traces. Search latency at 1M spans is not yet measured | FR-7 |
| 20 | 2026-11-16 | (Superseded the same day: Gemini via `google-genai` and the OpenAI Realtime API are now auto-instrumented; Realtime audio is assumed to be 16-bit PCM at 24 kHz, other formats are stored raw.) Speech-to-speech was first traced only for audio chat completions and manual spans | Patch WebSocket sessions and the Gemini SDK now | Both reach Tirkit today through manual spans or OpenTelemetry (OpenLLMetry instruments Gemini; Gemini also has an OpenAI-compatible endpoint). Native instrumentation is open work | FR-29 |
| 21 | 2026-11-17 | Root cleanup: `SPEC.md`/`PLAN.md` to `docs/`; `CONTRIBUTING.md`, `CLA.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` to `.github/` (GitHub still recognises them); `benchmarks/`, `experiments/`, `evals/` under `research/`; pytest/ruff/mypy caches and the built docs site under `.cache/` | Leave everything at the root | A tool people embed in their apps should look maintained. | 22 | 2026-11-17 | Public docs (README, SPEC, PLAN, DECISIONS, ROADMAP, docs site) are tracked; research notes, the study guide, the write-up draft and design notes live in git-ignored `docs/internal/` | Publish everything | Unverified competitor claims and personal notes should not ship; git worktrees do not contain ignored files, so work started in a worktree needs these copied in |
| 23 | 2026-11-17 | Performance targets stricter than Core Web Vitals "good": initial JS 120 kB gzip, LCP 1.2 s, INP 100 ms, CLS 0.02; trace list p95 100 ms at 1M spans; SDK p99 overhead at most 0.05 ms and at most 20% above the last baseline | Meet the industry thresholds only | Tirkit runs inside other people's apps and a UI people open all day; budgets are targets until measured and are enforced in CI only once baselined |
| 24 | 2026-11-17 | PII redaction has three modes: `off`, `secrets` (default for new projects), `strict`; redaction can run in the SDK background thread so data never leaves the app | On or off per project (previous behaviour, off by default) | High-precision secret patterns are safe to default on; broad personal-data patterns can corrupt IDs and need an informed choice |
| 25 | 2026-11-17 | Project renamed from Maat to Tirkit. Distribution, import name, CLI and environment prefix are all `tirkit` / `TIRKIT_`. Trademark search still to do |
